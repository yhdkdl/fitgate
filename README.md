# FitGate

FitGate is a multi-tenant gym management SaaS platform built for gyms and fitness centers.
It provides role-based access control for Super Admins, Gym Owners, Managers, Receptionists, Trainers, and Members.
Key features include automated QR-code attendance check-in, tiered membership plans, cash and online payments, AI-assisted workout plans, and finance tracking.
Each gym operates in strict tenant isolation with custom subdomains and dedicated branding.

For complete local setup instructions on a clean Windows machine using Docker Desktop and Git, see the [Local Setup Guide](docs/SETUP_LOCAL.md).
